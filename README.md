## 📝 Project Description

This is a full-stack blog writing platform that allows users to create and manage blogs with social features like friend connections and privacy settings. Users can register, log in, write blogs, and choose whether their content is public or visible only to friends. The platform supports a complete CRUD system for blogs and includes user management functionalities such as friend requests and a comment system.

---

## 🚀 Features

- ✅ User Authentication (Login & Signup)
- 📝 Create, Read, Update, Delete (CRUD) blogs
- 🔒 Privacy control: Public blogs or Private (visible only to friends)
- 🤝 Friend Request system
- 💬 Comment section on blogs
- 🧾 Blog listing (User's own blogs and public blogs)
- 👤 User Profile with blog stats
